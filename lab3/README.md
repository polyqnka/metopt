# Лабораторная работа: метод множителей Лагранжа

**Вариант:** 7  
**Номер в потоке:** 19  
**Вычисление варианта:** 19 mod 12 = 7

## 1. Постановка задачи

Для варианта 7 требуется найти условный минимум функции

f(x, y) = x² + y²

при ограничении

x + y = 4.

Также необходимо установить, существует ли условный максимум.

Ограничение записывается в стандартной форме:

g(x, y) = x + y - 4 = 0.

## 2. Результат ручного решения

Функция Лагранжа:

L(x, y, λ) = x² + y² + λ(x + y - 4).

Система необходимых условий:

- 2x + λ = 0;
- 2y + λ = 0;
- x + y - 4 = 0.

Из первых двух уравнений следует x = y.

Подставляем в ограничение:

2x = 4.

Получаем:

x = 2;
y = 2;
λ = -4.

Значение целевой функции:

f(2, 2) = 2² + 2² = 8.

Ограничение выполняется:

2 + 2 - 4 = 0.

## 3. Исследование глобальности

Из ограничения выражаем:

y = 4 - x.

Подставляем в целевую функцию:

f(x, 4 - x) = x² + (4 - x)².

После преобразования:

f(x, 4 - x) = 2(x - 2)² + 8.

Так как квадрат неотрицателен, функция принимает
минимальное значение 8 при x = 2.

Следовательно, глобальный условный минимум равен 8
и достигается в точке (2, 2).

Максимума нет, поскольку при неограниченном увеличении
по модулю x значение функции стремится к бесконечности.
