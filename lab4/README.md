# Лабораторная работа № 4: Решение многоэтапных оптимизационных задач методом динамического программирования

**Вариант 19:** «Общежитие на первых двух»  
**Цель работы:** освоить полный цикл решения многоэтапной оптимизационной задачи — от математической постановки и вывода рекуррентного соотношения Беллмана до ручных вычислений, программной реализации на Python и верификации результатов.

---

## Структура проекта

* `README.md` — описание проекта, инструкция по запуску и сводный отчёт о выполненной работе.
* `REPORT.md` — полный академический отчёт (постановка, вывод уравнения Беллмана, таблицы ручного счёта, ответы на контрольные вопросы).
* `data.json` — исходные данные варианта 19 (таблица выработки участков, общий ресурс и ограничения).
* `main.py` — программная реализация алгоритма динамического программирования (обратный и прямой проходы, вывод таблиц Беллмана $V_k(s)$ и множеств оптимальных управлений $A_k(s)$).
* `test_dp.py` — верификация решения полным перебором (`brute_force`) и набор модульных тестов (граничные и некорректные входные данные).

---
