# Лабораторная работа 1 — Симплекс-метод

**Вариант:** 19

## Задача

Решить задачу линейного программирования двухфазным симплекс-методом:

\[
\max Z = 4x_1 + x_2 + x_3 + 2x_4
\]

при условиях

\[
\begin{cases}
2x_1 + x_2 + x_4 \leq 9,\\
x_1 + x_2 + x_3 = 7,\\
x_3 + x_4 \geq 5,\\
x_1,x_2,x_3,x_4 \geq 0.
\end{cases}
\]

## Выполнение

В работе задача решена несколькими способами:

1. **Ручное решение** — приведение задачи к каноническому виду и решение двухфазным симплекс-методом с построением симплекс-таблиц.
2. **Python** — собственная реализация симплекс-метода без использования готовых оптимизационных солверов.
3. **Google Sheets** — дополнительная проверка результата с помощью Maxable Solver.

## Результат

Оптимальное решение:

\[
x^* = (0, 0, 7, 9)
\]

Максимальное значение целевой функции:

\[
Z_{\max} = 25
\]

Результаты ручного решения, собственной реализации на Python и проверки в Google Sheets совпадают.

## Запуск

Для запуска собственной реализации симплекс-метода:

```bash
python3 solver.py
```
