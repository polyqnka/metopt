# Лабораторная работа 2 — Метод ломаных

**Вариант:** 19

## Задача

Найти глобальный минимум одномерной функции методом ломаных Пиявского–Шуберта.

Исследуемая функция:

```text
f(x) = 10 + x² - 10·cos(2πx)
```

Интервал поиска:

```text
x ∈ [-1.8, 1.7]
```

Требуемая точность:

```text
ε = 0.01
```

Для работы метода используется константа Липшица:

```text
L = 70
```

## Выполнение

В работе реализован метод ломаных Пиявского–Шуберта на Python.

Алгоритм:

1. Задаются функция, интервал поиска и требуемая точность.
2. Вычисляются значения функции в концах интервала.
3. Для каждого соседнего отрезка строится нижняя оценка функции.
4. Следующая точка выбирается как точка пересечения соответствующих ломаных, а не перебирается по сетке.
5. Выбирается отрезок с наименьшей нижней оценкой.
6. В новой точке вычисляется значение функции.
7. Процесс повторяется до выполнения условия точности.

Для разбора строкового представления функции используется `SymPy`, для вычислений — `NumPy`, для построения графика — `Matplotlib`.

## Выбор константы Липшица

Для функции

```text
f(x) = 10 + x² - 10·cos(2πx)
```

производная имеет вид:

```text
f'(x) = 2x + 20π·sin(2πx)
```

На рассматриваемом интервале можно оценить модуль производной:

```text
|f'(x)| ≤ 3.6 + 20π ≈ 66.43
```

Поэтому в программе выбрано значение:

```text
L = 70
```

что обеспечивает небольшой запас относительно максимального значения модуля производной.

## Результат

Получено приближённое положение глобального минимума:

```text
x* ≈ 0.000019
```

Значение функции в найденной точке:

```text
f(x*) ≈ 0.00000007
```

Количество итераций:

```text
138
```

Время работы программы составляет около:

```text
0.004 с
```

Полученная точность удовлетворяет требованию:

```text
f(x*) - W ≈ 0.00996 ≤ ε = 0.01
```

где `W` — найденная нижняя оценка глобального минимума.
